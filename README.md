# AI Pulse API Health Monitor 🚀

Monitor your APIs in real-time, predict failures, and get AI-based suggestions (mocked for hackathon demo)!

## Features
- Continuous API monitoring at custom intervals.
- Logs API status codes and latency.
- Mocked AI-based analysis for failures and suggestions.
